전 API 500 — 커넥션 풀 고갈 원인 규명과 재발 감지

상황
관리자용 실시간 출석 피드(SSE) 배포 후 전 API가 500을 반환. 이미 동아리 회원들이 출석에 사용 중인 서비스.
접근

상황
프론트의 MediaPipe 결과(관절 33개, 화면+월드 좌표)를 그대로 중계하는 안이 출발점이었음.
접근

해결
월드 좌표만, 고정 순서 배열, 소수 3자리 형식을 제안(927B, 약 1/10). 서버는 2KB·참가자당 초당 15개 상한을 설정값으로 두고 넘는 메시지는 연결을 유지한 채 버림.
결과
5명·15Hz 중계 p95 9.5–12.3ms(3회 측정, 로컬 PC). 30Hz로 보내도 상한에서 잘려 지연 증가 없음. 다른 PC·배포 서버 경유 지연은 미측정으로 문서에 명시.
